Política de Privacidade

Fotos do Casamento de Samuel & Esthéfani · atualizada em 8 de outubro de 2026

O que é este site

Um site particular para os convidados do casamento de Samuel & Esthéfani enviarem as fotos e vídeos que registraram na festa. Não há fins comerciais, anúncios ou rastreamento.

Dados coletados

  • O nome que você digita, para identificar quem enviou cada arquivo.
  • As fotos e vídeos que você escolhe enviar e informações técnicas deles (nome do arquivo, tipo, tamanho, data de envio).
  • Um identificador aleatório guardado no seu navegador, usado apenas para limitar abusos de envio.

Não coletamos email, telefone, localização nem acessamos sua conta Google ou qualquer outra conta sua.

Como os dados são usados e armazenados

Os arquivos são salvos diretamente no Google Drive pessoal dos noivos, em uma pasta própria. Os registros de envio ficam em um banco de dados (Supabase). Somente os noivos têm acesso às fotos. Nada é vendido, compartilhado com terceiros ou usado para publicidade.

Uso das APIs do Google

O aplicativo usa a Google Drive API com o escopo drive.file, que permite acessar somente os arquivos e pastas criados pelo próprio aplicativo no Drive dos noivos. O uso de informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Por quanto tempo

As fotos ficam guardadas pelos noivos como recordação do casamento. Os registros técnicos de envio são apagados após o encerramento do período de envio.

Seus direitos

Você pode pedir aos noivos, a qualquer momento, a remoção das fotos que enviou ou dos seus dados, conforme a Lei Geral de Proteção de Dados (LGPD).
